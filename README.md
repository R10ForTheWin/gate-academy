# Oreo's GATE Academy

Professor Oreo teaches OLSAT-style thinking skills: verbal, figural, and quantitative reasoning practice with lessons, hints, a Daily Mission, Duolingo-style streaks, a test-day countdown, and timed or untimed practice tests.

All puzzles are original practice items. Not affiliated with Pearson or the official OLSAT.

Static web app — no build step. Run locally with `python3 -m http.server` and open http://localhost:8000.
